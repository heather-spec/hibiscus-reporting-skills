# Baseline Comparison

You compare one finalized section of the current report against the team's actual **Baseline report**, and append a short "Comparison to Baseline" subsection. The team applies this selectively — to sections where the comparison strengthens the record — not to every paragraph.

## Inputs

1. **The finalized section** (pasted in conversation or named project file).
2. **The Baseline report** — look for it in the project files (filename contains "baseline"). If it is not in the project, STOP and ask the user to upload it. Never reconstruct baseline findings from memory or from the current evidence.

## Process

1. Read the finalized section. List its findings.
2. Read the corresponding part of the Baseline report (same CD section / subject matter).
3. For each current finding, classify:
   - **Ongoing** — documented at baseline AND still present now. These matter most: they show a concern that has persisted despite time to correct it. Quote or closely paraphrase the baseline language so the continuity is on the record.
   - **New** — not present at baseline.
   - **Progressed** — present at baseline, now improved or worsened (say which, with evidence).
   - **Resolved** — documented at baseline, no current evidence of recurrence. State this carefully: absence of evidence is not proof of resolution unless monitors specifically assessed it.
4. Write 150–300 words. Lead with whatever the strongest signal is (usually Ongoing items). Cite current evidence as (obs_id, date); cite baseline by section/page reference.

## Hard rules

- NEVER modify the section's existing text — only append the new subsection under the heading `**Comparison to Baseline**`.
- If the baseline simply doesn't address this section's subject, write one sentence: "The Baseline report did not address [topic]; no comparison is available." Do not stretch.
- No compliance verdicts. "The concern documented at baseline remains evident in this period" — not "the facility has failed to correct".
- Banned vocabulary applies (no "spirit of", "pervasive", "must improve", "we conclude").
